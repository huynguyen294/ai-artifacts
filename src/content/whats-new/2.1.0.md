# Leaner MCP reads, atomic edits, and source-file artifact creation

Version **2.1.0** optimizes how AI clients read and update Markdown artifacts so large plans and specs stay fast without flooding model context windows.

## Compact metadata and bounded reading

- `inspect_artifact` and `join_session` now return compact `lineCount` and `byteSize` metadata alongside `artifactSha256` and `reviewRound`, omitting full Markdown content from lifecycle payloads.
- When an agent cannot read `artifactPath` with native filesystem tools—or wants a structural overview—the read-only `read_artifact` tool provides bounded `range` slices (with UTF-8 `byteOffset` continuation), Markdown `outline` extraction, and literal `search` hunks.

## Create from file and edit atomically

- **One-time file import (`sourcePath`):** Both `create_artifact` and `update_artifact` can copy content directly from an existing regular UTF-8 text file (up to 2 MiB), stripping any leading UTF-8 BOM while leaving the original file independent afterward.
- **Atomic search-and-replace (`edits[]`):** `update_artifact` now supports localized edits on original-text coordinates, preserving untouched bytes and CRLF/LF line endings.
- **Token-preserving validation:** Pre-commit input, `sourcePath`, and `edits[]` target errors return structured recovery fields with `reuseRoundToken: true`, allowing retries without forcing an extra re-inspection.

## Integration note

This release bundles numeric **MCP version 13**, **create-review-artifact skill v5**, and **work-session skill v2** (keeping schema v6 artifact storage and Work Session compatibility unchanged). After updating, automatic integration upgrade updates managed client configs and skills on startup—restart connected AI clients and start a fresh chat to pick up the updated tool definitions.
